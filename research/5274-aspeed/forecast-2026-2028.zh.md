## 0. 三个最重要的结论

1. **自下而上建模复现了卖方一致预期，而不是推翻它。** 中性情形2026年EPS **200元**、2027年
   **361元**，对一致预期的 **202元**、**368元**——误差1%—2%。**这意味着：在这档股票上，
   盈利预测不是一个可以产生分歧的地方。** 这与多数成长股相反，也与本仓库另一个案例
   （洁美科技，自下而上比一致预期低35%）恰好相反。
2. **分歧只能出现在退出倍数上，而倍数的敏感度是压倒性的。** 同一组中性盈利假设下，
   30倍对应13,159元（较现价 **−26%**），40倍对应17,546元（**−2%**），45倍对应19,739元
   （**+10%**）。**你对倍数的看法，比你对出货量的看法重要约五倍。**
3. **倒算估值在30倍这一档就撞上了物理上限。** 现价7,437亿元市值，以30倍终值反推需要248亿元
   净利、约7,000万颗出货——**而信驊自己对2030年全球BMC市场的预估是6,577万颗。**
   要让现价在30倍下成立，信驊必须在某一年卖出比它自己预测的2030年全球市场还多的芯片。
   现价真正隐含的，是 **45倍左右的终值**。

## 1. 模型结构与校准

模型按 **出货量 × 单价 × 毛利率** 自下而上搭建，因为这门生意就是这样运行的：信驊把可数的
芯片卖进可数的主机板，而管理层自己的成长叙事是**"同一片板子上更多颗芯片"**，不是"更多台
服务器"。

**校准锚点（新台币亿元）**

| 校准项 | 数值 | 来源／推导 |
|---|---|---|
| 2025年营业收入 | **90.85** | 合并财报9,084,875千元 |
| 2025年毛利率 | **68.01%** | 营业毛利6,178,705千元 |
| 2025年税后净利 | **39.28** | 3,927,807千元 |
| 2025年BMC出货 | **2,366.8万颗** | 对应BMC营收88.31亿元 → **隐含单价NT$373／颗** |
| 2026年上半年营收／净利 | **70.18 / 32.55** | Q1 31.47＋Q2 38.71；Q1 14.14＋Q2 18.41 |
| 2026年上半年净利率 | **46.4%** | 全模型最重要的一个校准点 |
| 隐含营业费用率（净额，含业外） | **2025年约16.0% → 2026年上半年约14.8%** | 由毛利率、净利率与17%税率倒算 |
| 所得税率 | **17%** | 由2025年数据反推，**未经财报验证** |
| 股本 | **4,158.3万股** | 2026年3月资本公积转增资后 |
| 股价 | **17,885元**（2026年9月11日） | 市值 **7,437亿元** |
| 汇率 | **30.5 NT$/US$，三年保持不变** | **刻意简化，见第5节的质疑** |

> **一处必须公开的口径冲突：** 公开引用的ASP序列称2025年服务器BMC ASP为 **US$13.7**，
> 但以实际BMC营收88.31亿元÷2,366.8万颗＝ **NT$373／颗**，按2025年均价约31.2换算仅
> **US$12.0**，相差约13%。最可能的解释是该US$13.7只涵盖"服务器BMC"而剔除了低阶／mini BMC。
> **本模型一律以实际营收校准，不采用外部ASP绝对值**，外部ASP仅用于检验增速方向。

## 2. 三种情形的核心假设

| 假设 | 悲观 | 中性 | 乐观 |
|---|---|---|---|
| **BMC出货（百万颗）** 2026/27/28 | 31.5 / 37.0 / 34.0 | **32.7 / 44.6 / 52.0** | 33.5 / 50.0 / 58.0 |
| **BMC单价（NT$／颗）** | 495 / 520 / 470 | **505 / 640 / 680** | 520 / 680 / 730 |
| 折合ASP（US$） | 16.2 / 17.0 / 15.4 | **16.6 / 21.0 / 22.3** | 17.0 / 22.3 / 23.9 |
| **周边芯片附加率**（占BMC营收） | 8.5% / 9.5% / 9.5% | **9.5% / 12% / 13%** | 10.5% / 14% / 15% |
| **毛利率** | 68.8% / 66.0% / 62.5% | **69.5% / 70.0% / 69.0%** | 70.0% / 71.5% / 71.5% |
| **营业费用率** | 14.8% / 16.5% / 19.0% | **14.2% / 13.5% / 14.0%** | 13.8% / 12.5% / 12.5% |
| **退出本益比** | **20x** | **35x** | **45x** |

**假设的立论依据：**

- **出货量。** 中性情形直接采用外资的4,460万颗（2027年）与顺势外推的5,200万颗（2028年）。
  **这不是保守假设——它已经等于信驊自身2030年TAM的68%与79%。** 乐观情形的5,800万颗
  ＝ **2030年TAM的88%，提前两年达成**，这已经是这条曲线在不上修TAM的前提下的物理上限。
  悲观情形假设2027年增速腰斩至4成以下、2028年出现一次类似2023年的库存修正（但幅度较轻：
  −8%，而非2023年的−40%）。
- **单价。** 中性2027年NT$640 ≈ US$21.0，与外部预估的US$21.7及管理层"有机会挑战US$20"
  一致，来源是AST2700／AST2750的产品组合上移。悲观情形假设第四季的两位数涨价在2028年
  被客户要回去——**这是合理的，因为管理层自己说那次涨价是成本转嫁**。
- **周边芯片附加率**是中性情形里最脆弱的一根柱子。2025年残值仅约BMC营收的2.9%，且其中还
  包含已于2025年12月31日分割出去的智慧影音业务。中性情形要求它在两年内升到12%——
  **这完全依赖AST1040／AST1080／AST1840的实际放量，目前没有任何公开的出货量数据可以验证。**
- **毛利率。** 2026年上半年实际约70.7%（Q1 69.18%、Q2 72%），但**公司给第三季的指引是
  67%—68%**。中性情形取全年69.5%，即承认第二季的72%是峰值而非新常态；2027年70%假设涨价
  的净效果为正。悲观情形把它压回62.5%，接近2023年式的产品组合与稼动率。
  **反向提示：公司自己说BIC毛利较低而占比在提升——附加率越高，毛利率越难维持，
  这两条假设在中性情形里是相互拉扯的。**
- **营业费用率。** 2025年约16.0%、2026年上半年约14.8%，中性情形假设继续降至13.5%。
  **这是全模型最可能出错的假设**：台湾《公司法》要求员工酬勞按当年度获利的比率提列，
  意味着营业费用随利润同比例放大，**营业杠杆在数学上被封了顶**。若员工酬勞机制不允许
  费用率降到13.5%，中性情形的EPS就要下修。悲观情形反其道而行，假设2028年费用率回到19.0%
  （利润下滑而人事费用刚性）。
- **退出本益比。** 20倍＝一门被重新认定为景气股的生意；35倍＝接近信驊长期中枢的
  高品质定价；45倍＝当前卖方实际在用的倍数（22,000元＝2027—2028年平均EPS×55倍；
  另有券商用2028年EPS×40—50倍）。

## 4. 倒算估值：现价要求什么

不向前预测，而是取市值反解所需利润——这是本仓库的标准做法，也是本案里最有信息量的一张表。

| 退出本益比 | 所需净利（亿元） | 所需EPS | 对2025年倍数 | 隐含营收（亿元） | 隐含出货（百万颗） | **占2030年TAM** |
|---|---|---|---|---|---|---|
| 25x | 297 | 715 | 7.6x | 626 | 84 | **127%** |
| **30x** | **248** | **596** | **6.3x** | **522** | **70** | **106%** |
| 35x | 212 | 511 | 5.4x | 447 | 60 | 91% |
| 40x | 186 | 447 | 4.7x | 391 | 52 | 79% |
| **45x** | **165** | **397** | **4.2x** | **348** | **46** | **71%** |
| 50x | 149 | 358 | 3.8x | 313 | 42 | 63% |
| 55x | 135 | 325 | 3.4x | 285 | 38 | 58% |

*隐含营收按2026年上半年47.5%净利率倒算；隐含出货按ASP US$24.6（NT$750，较2026年再涨48%）
倒算；TAM分母为信驊自身上修后的2030年全球BMC市场6,577万颗。*

**三条读数：**

1. **25倍与30倍在物理上不成立**——所需出货量超过公司自己预测的2030年全球市场总量。
2. **45倍是现价真正隐含的终值。** 所需EPS 397元恰好落在2027年券商预期区间（328—408元）的
   **上缘**。**当前价格 ≈ 2027年卖方预期以上缘兑现、按45倍资本化、不折现、此后不再成长。**
3. **这与卖方自述完全一致**，他们并不隐瞒：某欧系用2027—2028年平均EPS×55倍给22,000元；
   另有券商用2028年EPS×40—50倍。**市场公开地在为2028年的盈利、按接近历史上缘的倍数付钱。**

## 5. 敏感度：唯一真正重要的变量

**退出本益比（中性情形2028年EPS＝439元）**

| 退出本益比 | 隐含价值 | 较现价 |
|---|---|---|
| 20x | NT$8,773 | **−51%** |
| 25x | NT$10,966 | −39% |
| 30x | NT$13,159 | −26% |
| 35x | NT$15,353 | −14% |
| **40x** | **NT$17,546** | **−2%** |
| 45x | NT$19,739 | +10% |
| 50x | NT$21,932 | +23% |

**现价17,885元对应40.8倍的2028年中性EPS。**

**三情形的终值区间**

| | 2028E EPS | 退出倍数 | 隐含价值 | 较现价 |
|---|---|---|---|---|
| 悲观 | 152 | 20x | **NT$3,039** | **−83%** |
| 中性 | 439 | 35x | **NT$15,353** | **−14%** |
| 乐观 | 573 | 45x | **NT$25,803** | **+44%** |

**两端比值超过8倍。** 这不是模型不精确，而是这门生意的真实形状：**它在2023年一年之内
营收−39.9%、净利−52.2%，而当时它没有丢掉任何一个客户。** 悲观情形不是臆想的尾部，
它是三年前刚刚发生过的事，只是本模型假设它这次温和得多。

**其他被有意简化、但应当被质疑的假设：**

- **汇率固定在30.5。** 这是全模型最偷懒的一处。**2025年第二季营收环比+8.8%而EPS环比−29.0%**，
  最可能的解释是新台币急速升值造成的汇兑损失。**若这是真的，那么单季汇率波动可以吃掉三成
  利润，而本模型对此完全没有建模。** 建议以 ±5% 汇率对2027年EPS做一次单独扰动。
- **所得税率17%** 系由2025年数据反推，未经财报验证。台湾名目税率20%，未分配盈余加征5%；
  信驊配发率77%，研发投抵金额未知。**若实际税率为20%，中性情形2028年EPS由439元降至
  423元（−3.6%）。**
- **周边芯片附加率**（中性2027年12%）没有任何公开出货数据支持，纯属对管理层叙事的量化。
  **若附加率停在2026年的9.5%，中性情形2027年营收由319.7亿降至312.4亿，EPS由361元降至353元。**
  影响不大——**这说明"更多芯片种类"的故事，在数字上远不如"更多颗数×更高单价"重要。**
  这本身就是一个应当向管理层核实的结论。
- **未建模的结构性因素：** 酷博樂（Cupola360）向员工与外部释股后的少数股东权益、
  中国国产替代导致的区域性收入流失、DC-SCM模块化对换供应商成本的长期影响。

## 6. 怎么用这份模型

**不要用它来得出一个目标价。** 用它来回答三个问题：

1. **市场的盈利预期合理吗？** 合理。中性情形与一致预期误差1%—2%，且管理层有系统性低报高走
   的纪录（2025年第四季指引20—21亿、实际24.4亿；2026年第二季毛利率指引67%—68%、实际72%）。
   **在这档股票上做空盈利，大概率是错的。**
2. **那么你在为什么付钱？** 为 **40—45倍的2028年盈利**。这个倍数是否成立，取决于2028年之后
   的能见度——而公司自己说 **"2028年客户尚未正式下单，只有Design Win"**。
3. **什么会让模型失效？** 按影响力排序：**(a) 退出倍数**（±5倍＝±12%价值）；
   **(b) 2027—2028年出货量**（中性44.6／52.0百万颗，已达TAM的68%／79%，上行空间有限而
   下行空间很大）；**(c) 毛利率**（第三季67%—68%的指引是最近的一次公司自己给出的警告）；
   **(d) 汇率**（未建模，但历史上曾单季吃掉三成利润）。
