# 厂务工程的效率在哪里决定——柏诚股份 vs 圣晖集成的可量化对比

*运营效率专题 · 2026年8月31日修订（两家2026年半年报原文＋柏诚管理层访谈纪要）· 配套文件：[柏诚 vs 圣晖 对比备忘](cleanroom-601133-vs-603163.zh.md) · 仅为分析框架，不构成投资建议*

---

## 0. 先确定这门生意的效率变量是什么

厂务（洁净室系统集成）有三条硬约束，它们决定了哪些指标有意义、哪些没有：

1. **毛利率不是经营变量，是项目变量。** 客户是中芯国际、长鑫存储、三星、SK海力士、富士康这一级的
   买方，采用招标制、分包制、里程碑付款、留质保金。头部企业的毛利率长期锁在 **10%—15%**。
   更要紧的是：**单个大项目就能把半年的综合毛利率拉走一个百分点**（本文第4节给出一个实例）。
   所以"谁的毛利率高"这个问题，在半年这个尺度上几乎没有信息量。
2. **真正拉开差距的是周转。** 两家的净利率都在5%上下，谁的ROE高，几乎完全取决于同样一块钱资产
   一年能转几次收入。而资产周转率在这门生意里等价于一件事：**每做1元收入，要垫多少钱、垫多久。**
3. **垫资的钱从哪来，本身就是能力。** 应收账款和合同资产是"干完没收到钱的活"，应付账款和合同负债
   是"用了没付钱的料"和"业主先给的钱"。**一家厂务公司的真本事，是把下游的账期转嫁给上游、
   并让业主先付款，自己只承担中间那一段。** 这一段的长度，就是净营运资金周期。

本文只算四类指标：**杜邦拆解、净营运资金周期、人均效率、费用与计提。两家的2026年半年报原文
均已取得，所有数字可核到科目。**

## 1. 杜邦拆解：ROE差一倍，全部来自周转

| 2025年 | 柏诚股份 | 圣晖集成 | 差异 |
|---|---|---|---|
| 归母净利率 | 4.96% | 5.19% | 基本相同 |
| **总资产周转率** | **0.75次** | **1.27次** | **圣晖高69%** |
| 权益乘数（总资产/归母净资产） | 1.84倍 | 2.02倍 | 接近 |
| **＝ ROE** | **约6.9%** | **13.65%（加权）** | **圣晖是柏诚的2倍** |

*柏诚：2025年末总资产54.97亿元、归母净资产29.95亿元；圣晖：2025年末总资产23.60亿元、
归母净资产11.68亿元（均取自各自2026年半年报的期初数）。*

**两家的赚钱能力（净利率）几乎一样，杠杆也几乎一样，ROE差一倍，100%来自资产周转率。**
而周转率的差距只有一个来源，下一节直接给出。

| **经营活动现金流入／营业收入** | **56.6%** | **163.4%** |

**这张表是整篇文章的答案。** 两家都没有有息负债，都用上游账期融资，但**圣晖多了一样东西：
业主预收款相当于年化收入的13.9%，柏诚只有2.1%——差6.6倍。** 正是这3.03亿元的预收款
（同比+146%），把圣晖的净营运资金推成了负数：**它做工程不但不占用自己的钱，还反过来先收钱。**

后果是直接的：圣晖上半年经营现金流 **+3.59亿元**，账上现金占总资产46%；柏诚 **−6.06亿元**，
现金半年减少6.31亿元。**在同一个行业、同一个半年里，一家收进来的现金是收入的1.63倍，
另一家是0.57倍。**

**若柏诚的（应收＋合同资产）／收入降到圣晖的水平，可释放约 20.5亿元营运资金**——
是它想融的12亿元定增的1.7倍。

**为什么圣晖能收到预收款、柏诚不能？** 客户结构不同。圣晖41.9%的收入来自东南亚（越南、
泰国、马来西亚、印尼）的台资／外资电子厂，这类业主习惯按合同预付；柏诚91%的收入来自境内，
四大晶圆厂（长鑫、长存、中芯、华虹）**占其订单与收入至少70%**（管理层口径），
这类业主按里程碑付款、留质保金，且柏诚在其中一部分项目上还是总包商（十一科技、世源科技）
之下的分包方。**这不是管理水平的差别，是客户结构的差别——但它就是ROE差一倍的全部原因。**

## 3. 人均效率：拿单能力一样，变现效率不一样

**前提：两家的现场劳动力都靠劳务分包。** 柏诚在半年报风险提示里明确写"主要通过劳务分包方式
解决劳动力供应"。**所以人均创收衡量的不是工人产出，而是"一个正式编制的人能管多大产值"。**

| | 柏诚 | 圣晖 |
|---|---|---|
| 员工总数 | **约1,600人**（2026年8月，管理层口径；2025年末1,200人） | **838人**（2026年6月30日；2025年末762人） |
| 工程技术人员 | — | 716人（**85.4%**） |
| 一年内增员 | +33%（1,200→1,600） | +10%（762→838） |
| 人均创收（2025年） | 344万元 | **392万元** |
| 人均创收（2026H1年化） | **331万元** | 260万元 |
| 人均毛利（2026H1年化） | **35.6万元** | 33.0万元 |
| **人均净利（2026H1年化）** | 10.8万元 | **16.8万元** |
| 人均净利（2025年） | 17.1万元 | **20.3万元** |
| **人均在手订单** | **352万元** | **350万元** |
| 人均薪酬（2026H1支付现金年化） | 22.9万元 | 24.4万元 |

**三条读法：**

1. **人均创收在两家之间来回摆动**——2025年圣晖高，2026年上半年柏诚高——因为两家的收入在这半年
   朝相反方向走（柏诚+9.4%、圣晖−16.0%）。**这个指标在周期错位时不是有效的效率判据，
   不应作为结论依据。**
2. **人均在手订单几乎完全相同（352万 vs 350万）。** 这说明两家"每个人能拿到的活"是一样多的
   ——**拿单能力没有差距，差距在拿到的活值多少钱、多久能变成现金。**
3. **只有人均净利稳定地指向圣晖**（2025年、2026年上半年两个口径都高40%以上）。
   而人均薪酬两家接近（22.9万 vs 24.4万），说明这不是靠压低人工成本得来的。

**柏诚一年增员33%（1,200→1,600人）是一个需要单独跟踪的数字。** 管理层的解释是产能瓶颈在人、
"人堆出来才敢接单"，并称二次配业务招人最多。**这意味着2026年下半年的人工成本是刚性上升的：
若收入不能同步放量，人均指标会继续恶化。**

## 4. 费用与计提：费用率一样，结构完全不同

| 2026年上半年 | 柏诚 | 圣晖 |
|---|---|---|
| 销售费用率 | 0.60% | 0.18% |
| 管理费用率 | 3.32% | 2.91% |
| **研发费用率** | **0.13%** | **1.42%** |
| 财务费用率 | 0.16% | −0.41%（净收益） |
| **期间费用率合计** | **4.21%** | **4.10%** |
| **期间费用／毛利** | **39.3%** | **32.2%** |

**修正上一版的一处判断：** 上一版依据2025年年报口径称"圣晖的间接费用比柏诚轻约1.5个百分点"。
**用两家2026年上半年的原文数据看，费用率几乎相同（4.21% vs 4.10%）**——2025年的差距主要来自
当年圣晖收入大增48.85%摊薄了费用率。**结构性的差别不在总量，在构成：柏诚把钱花在管理上
（3.32%），圣晖花在研发上（1.42%，是柏诚的11倍）。** 以毛利为分母看，圣晖留下68%、
柏诚留下61%。

**计提政策：差距是实的，但一半可以由账龄解释。**

| 2026年6月30日 | 柏诚 | 圣晖 |
|---|---|---|
| 应收账款计提比例 | **14.11%** | 7.88% |
| 应收账款1年以上占比 | **34.1%** | 16.5% |
| **合同资产计提比例** | **6.68%** | **0.80%** |
| 其中"已完工未结算"计提 | 10.48%（按账龄，1年以上占53.2%） | **0.50%（统一比例）** |
| （应收＋合同资产）综合计提 | **8.04%** | **4.16%** |

两家的应收账款账龄阶梯其实接近（1—2年均为10%，3—4年均为50%，5年以上均为100%；
差别在2—3年，柏诚30%、圣晖20%）。**所以应收端7.88%对14.11%的差距，主要来自账龄结构
（圣晖83%在1年以内），不是政策更松。** 但**合同资产端是真的政策差异**：柏诚按账龄计提到
最高80%，圣晖对"已完工未结算"统一按0.50%。

**公平性调整：若圣晖按柏诚8.04%的综合比例计提，需多提约3,399万元，相当于其2026年上半年
归母净利润的48%。** 柏诚管理层在访谈中也主动提到这一点："我们提的比例同行业高……
亚翔、圣晖、中电他们提的比例低，你要去对比，大家都把它去掉之后再对比。"
**这个提醒是成立的，本文接受它：跨公司比净利润时，必须先把计提政策差异摆出来。**

## 5. 两个必须写进来的反面证据（否则会高估圣晖）

**其一：圣晖上半年的利润增长，全部由减值转回解释。**

| 2026年上半年 | 金额 |
|---|---|
| 信用减值损失（正数为转回） | ＋1,220万元 |
| 资产减值损失（正数为转回） | ＋104万元 |
| **减值合计贡献** | **＋1,324万元＝利润总额的12.7%** |
| 上年同期减值合计 | −475万元 |
| **同比多贡献** | **＋1,799万元** |
| 利润总额同比增加额 | ＋1,721万元 |

**减值科目的同比改善（1,799万元）大于利润总额的全部增加额（1,721万元）。剔除减值，
圣晖上半年税前利润同比 −0.9%，是持平的。** 需要同时说明的是：**这些转回是真实回款的会计结果**
（应收账款半年减少33%、经营现金流+3.59亿元），不是账务操作；**但它不可持续——
你只能转回以前计提过的。**

**其二：柏诚上半年的毛利率被一个具体项目拉低，不是全面降价。**

柏诚管理层在访谈中给出了解释：上半年有一个**中芯国际的电力包项目，合同额6亿多元，
设备材料占比高、安装少、工期短（"短平快"），二季度单季就确认了约4.8亿元产值，
毛利率约7%**。按此倒算：

- 二季度收入17.92亿元、毛利率约10.14%；剔除该项目后，其余13.12亿元的毛利率约 **11.3%**
- 上半年26.52亿元、毛利率10.72%；剔除该项目后，其余21.72亿元的毛利率约 **11.6%**，
  较上年同期的10.14%提升约1.4个百分点——与管理层所说的"同比提升1.665个百分点"基本吻合

**这修正了本文上一版和柏诚备忘录中的一处判断。** 此前基于分业务毛利率同时下滑，判断
"下滑是全面的、是定价问题"；**加入项目层面的信息后，更准确的表述是：上半年毛利率的
绝对水平被一个低毛利大项目稀释，剔除后同比是改善的；但分业务毛利率（一次侧11.05%→10.09%、
二次配14.43%→13.01%、境外15.07%→11.30%）同时下滑仍然成立，这两件事可以并存
——因为那个电力包项目本身就落在"一次侧／境内"这两个口径里。**
**结论从"全面降价"下调为"结构稀释为主、定价压力仍在"，需要三季度数据来最终区分。**

## 6. 结论

**按厂务行业自己的标尺——周转而非毛利率——圣晖明显更高效，而且原因可以定位到一个科目：**

- ROE差一倍（13.65% vs 6.9%），**100%来自总资产周转率**，净利率与杠杆几乎相同；
- 周转率的差距来自净营运资金周期：**柏诚+79天，圣晖−14天，差93天**；
- 这93天的机制是业主预收款：**占年化收入的比例，圣晖13.9%、柏诚2.1%**；
- 后果：**上半年经营现金流 +3.59亿 vs −6.06亿；现金收入比 163% vs 57%。**

**但差距的来源是客户结构，不是管理能力。** 圣晖41.9%的收入来自东南亚外资电子厂（预付款文化），
柏诚70%以上的订单来自四大境内晶圆厂（里程碑付款＋质保金）。**两家的人均在手订单几乎完全
相同（352万 vs 350万）——拿活的能力没有差距。**

**同时，两条反向证据必须并列：** 圣晖上半年的利润增长全部由减值转回解释（剔除后税前利润
同比持平），且其合同资产计提比例仅0.80%（柏诚6.68%），按柏诚口径重提将吃掉其48%的半年利润；
柏诚上半年的毛利率则被一个6亿元的低毛利短平快项目稀释，剔除后同比是改善的。

**所以最准确的表述是：圣晖的商业模式在现金上明显更优，而这个优势主要是客户给的；
柏诚的问题是它服务的客户不预付，而它正在用33%的增员去接更多这样的活。**
**判断柏诚能否收敛的检验点很具体：三季度合同负债能否从1.12亿元实质性上升
（说明新签大单开始拿到预付款），以及收现比能否回到60%以上。**

## 7. 仍未取得的数据

1. **圣晖的未到期保函余额**——柏诚是10.87亿元（占年化收入20.5%），是厂务公司真实的授信占用，
   直接约束接单能力；圣晖半年报未见披露。
2. **两家的直签业主／分包收入拆分**——柏诚可从欠款方结构推断（总包方占应收＋合同资产16.28%），
   圣晖前五大欠款方中有四家匿名（合计29.8%），无法判断其中总包方占比。
3. **圣晖的员工薪酬构成与境外员工占比**——其人均薪酬24.4万元包含越南、泰国、印尼员工，
   与柏诚的境内口径不完全可比。
4. **柏诚2026年上半年二次配的单独毛利率**——半年报按商品类型披露了二次配13.01%，
   但未拆分境内外，而管理层称二次配"去年全年将近14.5%、上半年一般偏低因为决算在下半年"。
