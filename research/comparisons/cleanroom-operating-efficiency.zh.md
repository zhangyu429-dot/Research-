# 厂务工程的效率在哪里决定——柏诚股份 vs 圣晖集成的可量化对比

*运营效率专题 · 2026年8月30日 · 配套文件：[柏诚 vs 圣晖 对比备忘](cleanroom-601133-vs-603163.zh.md) · 仅为分析框架，不构成投资建议*

---

## 0. 先确定这门生意的效率变量是什么

厂务（洁净室系统集成）有三条硬约束，它们决定了哪些指标有意义、哪些没有：

1. **毛利率不是经营变量，是行业变量。** 客户是中芯国际、三星、SK海力士、富士康这一级的买方，
   采用招标制、分包制、里程碑付款、留质保金。国内头部企业的毛利率长期锁在**10%—15%**，
   两家公司2025年分别是11.93%和10.25%——**差异1.7个百分点，不足以解释任何东西。**
   拿毛利率比高低，是在比谁运气好、项目结构好，不是在比谁能力强。
2. **真正拉开差距的是周转。** 净利率都在5%上下，谁的ROE高，几乎完全取决于同样一块钱资产
   一年能转几次收入。而资产周转率在这门生意里等价于一件事：**每做1元收入，要垫多少钱、
   垫多久。**
3. **垫资的资金从哪来，是能力的一部分。** 应收账款和合同资产是"已经干完但没收到钱的活"，
   应付账款和应付票据是"已经用掉但没付钱的料和分包"。**一家厂务公司的真本事，是把下游的
   账期尽可能转嫁给上游，自己只承担中间那一段。** 这一段的长度，就是净营运资金周期。

所以本文只算四类指标：**杜邦拆解、垫资周期、人均效率、管理与订单效率。**

**数据口径的诚实说明：** 柏诚的全部数据来自其2026年半年度报告原文（230页全文已取得），
可以算到科目级；**圣晖的数据来自二手摘要，缺少应付账款、应付票据、合同负债的明细，
因此无法计算它的完整净营运资金周期**，且部分数据的时点是2025年中或2025年末，
与柏诚的2026年中不完全可比。**凡是时点不一致的，表中均已标注。**

## 1. 杜邦拆解：ROE差了一倍，全部来自周转

这是整篇文章最重要的一张表。

| 2025年 | 柏诚股份 | 圣晖集成 | 差异 |
|---|---|---|---|
| 归母净利率 | 4.96% | 5.19% | 基本相同 |
| **总资产周转率** | **0.75次** | **1.29次** | **圣晖高72%** |
| 权益乘数（总资产/归母净资产） | 1.84倍 | 1.98倍 | 接近 |
| **＝ ROE** | **约6.9%** | **13.65%（加权）** | **圣晖是柏诚的2倍** |

*柏诚：2025年末总资产54.97亿元、归母净资产29.95亿元；圣晖：按2025年末归母净资产11.68亿元
与资产负债率49.60%倒算总资产约23.17亿元。两者均以年末资产为分母，口径一致。*

**结论非常干净：两家公司的赚钱能力（净利率）几乎一样，杠杆也几乎一样，
ROE差一倍，100%来自资产周转率。** 而资产周转率差在哪里，下一节直接给出答案。

## 2. 垫资周期：柏诚每做1元收入要占用264天，圣晖是164天

### 2.1 柏诚的完整拆解（2026年6月30日，收入按上半年年化53.03亿元）

| 占用资金的科目 | 金额 | 折合天数 |
|---|---|---|
| 应收账款（净额） | 5.68亿元 | 39天 |
| **合同资产（净额）** | **27.51亿元** | **189天** |
| 长期质保金（列示于其他非流动资产） | 1.58亿元 | 11天 |
| 存货 | 1.88亿元 | 13天 |
| 预付款项 | 1.19亿元 | 8天 |
| 应收票据＋应收款项融资 | 0.54亿元 | 4天 |
| **占用小计** | **38.38亿元** | **264天** |

| 提供资金的科目 | 金额 | 折合天数 |
|---|---|---|
| 应付账款 | 17.79亿元 | 122天 |
| 应付票据 | 7.06亿元 | 49天 |
| 合同负债（业主预收款） | 1.12亿元 | 8天 |
| 应付职工薪酬＋其他应付款 | 1.04亿元 | 7天 |
| **提供小计** | **27.01亿元** | **186天** |

> **净营运资金＝11.36亿元，折合78天收入。**

**这张表有两个方向相反的读法，都要说：**

**利空的一半：** 264天的占用里，**189天是合同资产**——已经干完、还没结算、连账单都还没开出去的活。
其中"已完工但尚未结算"部分原值10.77亿元，**账龄1年以上的占53.2%**；应收账款账龄1年以上的
占34.1%。**两项1年以上的合计7.07亿元，是上半年归母净利润的8.2倍。**

**利多的一半（容易被忽略）：** 柏诚用**186天的上游账期**顶掉了264天占用里的七成。
应付账款＋应付票据合计24.86亿元，相当于应收＋合同资产33.18亿元的**75%**。
**这是真实的供应链议价能力——一家没有有息负债的公司，靠供应商和分包商的账期在给业主垫资。**
但这也意味着一个脆弱点：**若上游账期收紧20天，柏诚需要立刻补充约2.9亿元资金。**

### 2.2 圣晖能算出来的部分

| | 柏诚（2026/6/30） | 圣晖（2025/6/30） |
|---|---|---|
| 应收账款＋合同资产（净额） | **33.18亿元** | **11.66亿元** |
| 占总资产比例 | 56.33% | 52.65% |
| **占年化收入比例** | **62.6%** | **45.0%** |
| **折合天数** | **228天** | **164天** |

*柏诚年化收入53.03亿元；圣晖以2025年上半年收入12.95亿元年化为25.90亿元。*

**同一口径下，柏诚每做1元收入要多垫64天。** 换算成绝对额：若柏诚的垫资强度降到圣晖的水平，
它可以释放出约 **9.3亿元** 的营运资金——相当于它7月低点市值的7%，也差不多是它想融的
12亿元定增的四分之三。**"为什么要定增"这个问题，答案就在这64天里。**

**必须标注的口径缺陷：圣晖的应付账款、应付票据、合同负债明细未取得，因此无法计算它的净营运
资金周期。** 已知的线索是：圣晖2025年应付账款同比+41.63%、合同负债同比+38.91%（预收工程款
增加），说明它也在使用上游账期与业主预收款——**但用了多少，本次无法量化。这是本文最大的
数据缺口。**

### 2.3 现金真的收回来了吗

| | 柏诚 | 圣晖 |
|---|---|---|
| **经营活动现金流入／营业收入** | **56.6%**（2026H1）· 64.2%（2025H1） | **82.0%**（2025年） |
| 销售商品、提供劳务收到的现金 | 14.82亿元（2026H1，**同比−3.8%，而收入+9.4%**） | 经营性现金流入24.52亿元（2025年，+15.64%） |
| 经营现金流／归母净利润（2024） | **101%** | −3% |
| 经营现金流／归母净利润（2025） | 38% | **93%** |
| **两年合计（2024＋2025）** | **70%** | **52%** |
| 2026年上半年经营现金流 | **−6.06亿元** | 一季度已转正（公司口径） |

**这一组必须公平地读。** 单看2025年，圣晖（93%）碾压柏诚（38%）；但**把2024和2025两年合起来
看，柏诚反而更好（70% vs 52%）**——因为圣晖2024年的经营现金流是负的。
**真正确定的不是"谁历来收款好"，而是"2026年两者在朝相反方向走"：**
柏诚的收现比从64.2%降到56.6%（每1元收入只收回0.57元），圣晖的现金流则由负转正并延续。

## 3. 人均效率：口径比数字重要

**先说一个必须先说的前提：这两家公司的现场劳动力都主要靠劳务分包。** 柏诚在半年报风险提示里
写得很明白——"公司目前主要通过劳务分包方式解决上述劳动力供应问题"。
**所以人均创收在这个行业里衡量的不是工人产出，而是"一个正式编制的项目管理人员能管多大的
产值"，即管理半径。**

| | 柏诚 | 圣晖 |
|---|---|---|
| 员工总数 | 1,116人（**2023年末，最后可得**） | **762人**（2025年末，+6.72%） |
| 其中工程/项目技术人员 | 785人（2023年） | **642人（占84%）** |
| **人均创收** | 357万元（2023年） | **392万元**（2025年） |
| 按技术人员口径的人均创收 | 507万元（2023年）· 426万元（2022年） | 466万元（2025年） |
| **人均创利** | 19.2万元（2023年） | **20.3万元**（2025年） |
| 人均在手订单 | 504万元（按2023年人数、2026年6月订单） | 385万元（2026年二季度订单／2025年人数） |

**这组数字的可信度低于前两节，原因写在这里：柏诚2024与2025年末的员工总数本次未能取得**
（年报正文被网络出口屏蔽），只能用2023年末的1,116人。若柏诚2025年人数已增至1,300—1,400人
（考虑到它的收入规模是圣晖的1.4倍、且2022→2023年就增了21%，这是合理区间），
则其人均创收降至 **295万—318万元**，**较圣晖低20%—25%**。**方向上圣晖更精简，
但幅度未经证实。**

**一个可以确证的旁证：** 柏诚2026年上半年"支付给职工及为职工支付的现金"1.83亿元，
占收入 **6.9%**；圣晖未披露同口径数据，但其**期间费用率比柏诚低约1.4个百分点**（见下节），
而人工是期间费用的主要成分。

## 4. 管理效率与技术投入：一个更省，一个更肯投研发

| 2025年 | 柏诚 | 圣晖 |
|---|---|---|
| 销售费用率 | — | 0.18% |
| 管理费用率 | — | 2.21% |
| 研发费用率 | 约0.1%（2026H1为**0.13%**） | **1.05%** |
| 财务费用率 | — | 负（净利息/汇兑收益） |
| **销售＋管理＋财务合计** | **1.79亿元＝4.33%**（同比+47.38%） | — |
| **销售＋管理＋研发＋财务合计** | 约4.4% | **2.91%**（2024年3.44%） |

**两条结论：**

1. **圣晖的间接费用比柏诚轻约1.5个百分点。** 放在柏诚41.33亿元的收入上，1.5个百分点＝
   **约6,200万元，相当于柏诚2025年归母净利润的30%。** 而且柏诚的三费同比增长47.38%，
   是在收入下降21%的一年里增长的——**规模缩了、费用涨了，这是管理效率恶化的直接证据。**
2. **研发强度差了8倍：柏诚约0.13%，圣晖1.05%。** 柏诚的专利以97项实用新型为主、发明专利
   仅3项。**对一家被按科技股定价、市盈率63倍的公司，0.13%的研发费用率需要一个解释；
   而圣晖在规模更小的情况下把研发投入维持在1%以上，且工程技术人员占员工总数的84%。**

## 5. 订单与业务能力：谁在价值链的更高一层

| | 柏诚 | 圣晖 |
|---|---|---|
| 在手订单（2026年中） | **56.29亿元（+222%）** | 29.30亿元（+4.13%） |
| **订单覆盖倍数**（订单／年化收入） | 1.06倍 | **1.35倍** |
| 订单确认期限（公司口径） | 12—24个月 | 未披露 |
| 境外订单占比 | 6.23% | **53.7%** |

| 境外毛利率 | 11.30%（2025年15.07%，**塌了3.77pp**） | "境外项目毛利率稳步提升"（公司口径） |

| 客户等级 | 12英寸晶圆厂（中芯、华虹、长鑫、长存、三星、SK海力士）＋京东方、药明生物、阿斯利康 | 矽品、中芯国际、富士康、三安、友达、歌尔、华润微、晶合＋东南亚PCB/封测 |
| 订单披露频率 | 半年报／年报 | **按季度发布经营情况报告** |

**三点判断：**

1. **柏诚的订单获取能力在这一轮明显更强**，且拿的是技术等级最高的12英寸晶圆厂项目——
   这是真实的业务能力，不是财务技巧。
2. **但柏诚有相当一部分收入是在别人的总包下做分包**（十一科技、世源科技合计占应收＋合同资产
   16.28%，且这两家的坏账计提率7.4%和12.8%明显高于业主客户中车时代的5.1%——**总包方结算
   更慢**）。**做分包意味着价格不是自己定的，这在结构上解释了为什么它的洁净室系统集成业务
   毛利率只有8.94%。**
3. **圣晖的披露纪律更好。** 它按季度公布在手订单余额并拆分境内外，柏诚只在半年报和年报披露。
   **对一门收入完全由在手订单决定的生意，季度订单披露是实打实的治理优势。**

## 6. 三项必须做的公平性调整

不做这三项调整，上面的对比会系统性地高估圣晖。

**调整一：坏账计提政策差异。** 柏诚应收账款整体计提比例 **14.11%**（1年以上账龄占34.1%），
合同资产计提6.68%；圣晖应收账款计提比例 **6.08%**，公司自述"低于同行业可比公司10%以上的
平均水平"。**若把圣晖2025年末6.09亿元应收账款按柏诚14.11%的比例重新计提，需多提约0.49亿元
——相当于其2025年归母净利润的32%。** 圣晖的账龄结构可能确实更年轻（境外项目回款快），
但**这个差异必须在比较净利润和ROE时被记住：一部分"效率优势"可能是计提政策的优势。**

**调整二：圣晖2026年上半年的利润含坏账转回。** 公司明确表述利润增长部分来自"转回计提的
应收账款坏账金额较高"。**在收入同比−16%的半年里靠转回把利润做正，这不是可持续的经营效率。**

**调整三：时点与口径不一致。** 柏诚的数据是2026年6月30日（一手），圣晖多为2025年中／2025年末
（二手）。**在一个订单和现金流都在剧烈变化的行业里，一年的时点差足以改变结论方向。**
最典型的例子就是上文2.3节：单年比较和两年比较给出了相反的答案。

## 7. 结论

**按厂务行业自己的效率标尺——周转而非毛利率——圣晖明显更高效，而且高效的原因是可以定位到
科目的：**

- ROE差一倍（13.65% vs 6.9%），**差距100%来自总资产周转率（1.29次 vs 0.75次）**，
  净利率和杠杆几乎一样；
- 周转率的差距，来自垫资强度：**每1元收入的应收＋合同资产占用，柏诚228天、圣晖164天**，
  差64天；若柏诚降到圣晖的水平，可释放约9.3亿元营运资金；
- 间接费用轻约1.5个百分点（约合柏诚净利润的30%），且柏诚的三费在收入下降的一年里
  逆势增长47%；
- 研发强度高8倍（1.05% vs 0.13%），工程技术人员占比84%。

**但柏诚在两项真正属于"业务能力"的指标上更强：订单获取（在手订单+222% vs +4.13%，
且是12英寸晶圆厂）和上游议价（用186天的应付账期顶掉264天占用的七成，在零有息负债下完成
33亿元的垫资）。**

**所以准确的表述是：圣晖是一家更会赚钱的公司，柏诚是一家更会拿活的公司。**
在毛利率被业主锁死的行业里，"更会赚钱"通常更值钱——因为拿活的能力最终也要通过周转变现，
而柏诚2026年上半年的数据显示，它拿到的活正在以更低的毛利率、更慢的回款转化。

**这个判断的翻转条件是可量化的：柏诚需要把（应收＋合同资产）／收入从62.6%降到55%以下，
同时把三季度单季毛利率做到11%以上。** 前者意味着56亿元在手订单能在不额外占用营运资金的
前提下转化，后者意味着订单是以正常价格拿到的。**两者同时发生，柏诚的订单优势就会压过
圣晖的周转优势；只要有一个不成立，圣晖的效率优势就会继续扩大。**

## 8. 本次未能取得、直接影响结论的数据

1. **圣晖的应付账款、应付票据、合同负债明细**——没有它就算不出圣晖的净营运资金周期，
   而这是本文的核心指标。柏诚是78天，圣晖是多少，未知。
2. **柏诚2024与2025年末的员工总数**——人均效率一节因此只能用2023年末的1,116人，
   结论方向可信、幅度不可信。
3. **圣晖2026年半年报全文**——毛利率、经营现金流、坏账转回的具体金额均未取得。
4. **圣晖的未到期保函余额**——柏诚是10.87亿元（占年化收入20.5%），这是厂务公司真实的
   授信占用，直接约束接单能力；圣晖的对应数字未知。
5. **两家的直签业主／分包收入拆分**——柏诚可从欠款方结构推断（总包方占16.28%），
   圣晖完全未知。
