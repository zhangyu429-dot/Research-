# 柏诚股份（601133）vs 圣晖集成（603163）— 同一条赛道上的两笔不同生意

*对比备忘 · 2026年8月30日 · 仅为分析框架，不构成投资建议*

---

## 0. 先说结论

**这两只股票在市场眼里是同一笔交易，在报表里却是两门不同的生意。**

同一笔交易的证据很硬：**两只股票都从2025年11月起上涨（柏诚+237.96%，圣晖+168.53%），
都在2026年6月下旬见顶并同时发布"股价已严重偏离基本面"的异动公告，然后都在7月的三周里
腰斩。** 柏诚从6月29日的42.11元跌到7月21日的24.66元（−41%），圣晖从6月26日的135.58元跌到
7月20日的73.82元（−46%）。这是一次"洁净室＋半导体资本开支"主题的整体重定价，
个体基本面在其中几乎不起作用。

两门不同生意的证据同样硬：

| 一句话概括 | 柏诚股份 601133 | 圣晖集成 603163 |
|---|---|---|
| 你买的是什么 | **国内晶圆厂建设量的杠杆**：订单爆发、毛利率下滑、现金被订单吃掉 | **东南亚电子资本开支的现金流**：订单平淡、毛利率与回款更好、分红实在 |
| 最强的一条 | 在手订单**+222%** | 净资产收益率**13.65%**、经营现金流**+1.44亿** |
| 最弱的一条 | 一次侧／二次配／境外**毛利率同时下滑**，收现比降至55.9% | 在手订单同比仅**+4.13%**，增长引擎熄火 |

**如果只能深入一个：圣晖更值得花时间。** 你为每一单位ROE付出的价格比柏诚低约四成，
现金是真的收得回来，分红率52%是真的发得出来。**但如果你要的是"中国大陆晶圆厂建设"这个
风险敞口本身，只有柏诚有——圣晖的在手订单里53.7%在境外，且总量一年只多了4%。**

## 2. 三条决定性的差异

### 差异一：一个在用毛利率换收入，另一个在用收入换毛利率

这是2026年上半年两家公司最干净的对照：

| 2026年上半年 | 柏诚 | 圣晖 |
|---|---|---|
| 收入 | **+9.4%**（二季度+29.2%） | **−16.0%** |
| 归母净利润 | +3.0% | **+11.9%** |
| 方向 | 收入涨、利润率跌 | **收入跌、利润率涨** |

**柏诚**：二季度收入同比+29.2%，同季毛利率从一季度的11.94%降到约10.14%。半年报附注给出的
分业务数据把原因钉死了——**一次侧11.05%→10.09%、二次配14.43%→13.01%、境外15.07%→11.30%，
三条线同时下滑**，其中毛利率最高的二次配跌得最多。综合毛利率之所以还能同比+0.58个百分点，
**完全靠二次配占比提升在往上托，而每一类业务自身都在变差。**

**圣晖**：收入同比−16%（境外在建项目进入竣工结算，新项目还在前期施工），但归母净利润
+11.9%、扣非+12.5%，公司归因于"**境外项目毛利率稳步提升，本期回款良好，转回计提的应收账款
坏账金额较高**"。一季度毛利率已回升至11.86%（上年同期9.76%）。

**这两种模式在周期里的含义完全不同。** 柏诚的模式是典型的工程承包商放量期：抢单、压价、
垫资、赌规模效应；2024年已经演过一次（收入+31.8%、利润−0.8%、毛利率跌到10.00%），
现在正在演第二次。圣晖的模式是把已完工项目结算干净、把毛利率修好，再接新的——
**代价是收入和订单的增长看起来很难看。**

**需要对圣晖打的折扣：** 上半年利润增长里有"坏账转回"的成分，这不是可持续的利润来源；
且圣晖的应收账款坏账计提比例为**6.08%**，明显低于同业10%以上的水平（柏诚的应收账款整体
计提比例是**14.11%**）。**同一笔应收，柏诚按14%计提、圣晖按6%计提——这个差异需要在
比较净利润时被记住。**

### 差异二：一个的订单在爆发，另一个的订单在原地踏步

这是柏诚唯一的、但确实很硬的优势：

| | 柏诚 | 圣晖 |
|---|---|---|
| 2026年6月30日在手订单 | **56.29亿元** | 29.30亿元 |
| 同比 | **+222.15%** | +4.13% |
| 上半年新签 | **58.33亿元（历史新高）** | 未单独披露 |
| 7月1日—8月25日新签 | 10.34亿元 | — |
| 订单／2025年收入 | 1.36倍 | 0.98倍 |
| 主要来源 | 境内半导体及泛半导体（新签占80%以上） | 境外53.7%（越南／泰国PCB与精密制造、马来西亚封测、印尼传统行业） |

**这不是同一个下游。** 柏诚接的是中芯国际、华虹、长鑫、长江存储、三星、SK海力士的12英寸
晶圆厂——**大陆半导体建厂潮的正面敞口**；圣晖接的是矽品、富士康、三安、友达、歌尔、
华润微、晶合，以及东南亚的PCB、精密制造、封测、鞋类食品——**东南亚电子产业转移的敞口，
技术等级更低、单体更小，但客户付款条件与毛利率更好。**

**所以这条差异的真实含义是：** 如果你相信"大基金三期＋长鑫长存上市＋华虹Fab9B"这条线，
柏诚是唯一能拿到弹性的标的；如果你相信"中国＋1的产能外迁还有很长的路"，圣晖是那个。
**但柏诚的订单弹性已经用毛利率付了费，而圣晖的毛利率修复还没有订单来兑现。**

**同时要注意柏诚订单的减速：** 月均新签从1—4月的约11.1亿元，降到5—6月的约7.3亿元，
再到7月1日—8月25日的约5.65亿元。**仍是2025年（3.14亿元／月）的近两倍，但"集中释放"
的解释已经有了数据支持。**

### 差异三：一个在消耗现金并要融资，另一个在产生现金并分红

| | 柏诚 | 圣晖 |
|---|---|---|
| 2025年经营现金流 | +0.77亿元（净利润的38%） | **+1.44亿元（净利润的93%）** |
| 2024年经营现金流 | +2.15亿元 | −0.04亿元 |
| 2026年上半年经营现金流 | **−6.06亿元** | 一季度已转正（公司口径） |
| 上半年收现比 | **55.9%**（上年同期63.6%） | 未获取 |
| 应收＋合同资产 | 33.18亿元＝**总资产56.33%** | 应收账款6.09亿元（2025年末） |
| 1年以上账龄 | 7.07亿元＝上半年利润的**8.2倍** | 未获取 |
| 有息负债 | 0（但有10.87亿元未到期保函） | 未获取 |
| 分红率 | 30.6%—30.9% | **约52%** |
| 在途融资 | 12亿元定增，含3.6亿补流，**半年报未提及** | 5.5亿元可转债，**全额投项目、不补流，已上会通过** |

**这一条差异最能说明两家公司所处的阶段。** 柏诚正处在"订单先行、现金后至"的扩张前段：
合同资产以收入4.4倍的速度膨胀，货币资金半年减少6.31亿元，收现比降到55.9%（每1元收入
只收回0.56元现金），于是需要12亿元股权融资——**而这笔融资在半年报"重要事项"里完全没有
出现**，公司转而把IPO剩余超募资金1.35亿元投向同类项目。

圣晖走的是另一条路：2025年经营现金流+1.44亿元、覆盖净利润的93%，分红率52%，
再融资走的是5.5亿元可转债、全额投项目、不补流，并已于2026年6月16日通过上交所上市委审议。
**同样是要钱扩产，一个稀释股东最多30%，另一个先发债、先分红。**

## 3. 反向估值：两座桥，哪一座更短

给洁净室工程总承包同样的终局市盈率 **20倍**：

| | 柏诚（市值129.76亿元） | 圣晖（市值73.82亿元） |
|---|---|---|
| 20倍所要求的归母净利润 | **6.49亿元** | **3.69亿元** |
| 相当于2025年利润的 | **3.2倍** | **2.4倍** |
| 按各自当前净利率倒推所需收入 | 3.24%（2026H1）→ **200亿元** | 6.43%（2026H1）→ **57亿元** |
| 按各自历史最好净利率倒推 | 9.12%（2022）→ 71亿元 | 10.0%（2023）→ 37亿元 |
| 2025年实际收入 | 41.33亿元 | 29.89亿元 |
| 所需收入／2025年收入（按当前净利率） | **4.8倍** | **1.9倍** |

**两座桥都不短，但圣晖那座明显更短，而且它的桥墩（净利率、ROE、现金流）更结实。**
柏诚需要收入变成现在的4.8倍才能在当前净利率下撑起市值；圣晖只需要1.9倍。
即便都假设各自回到历史最好的净利率，柏诚需要71亿元收入（历史峰值52.44亿元的1.35倍），
圣晖需要37亿元（历史峰值29.89亿元的1.24倍）。

**注意这个倒算对两家都是"不通过"，只是不通过的程度不同。** 在7月的低点上，两只股票
仍然分别对应63倍和48倍的2025年市盈率——**这条赛道上没有便宜货，只有相对更贵和相对
没那么贵。**

## 4. 各自最锋利的那个风险

**柏诚：分业务毛利率已经证明，放量与降价是同一件事。**
上半年一次侧、二次配、境外三条线毛利率同时下滑，占收入47%的洁净室系统集成毛利率只有
**8.94%**，占收入76%的半导体业务毛利率只有**10.05%**——**被市场按半导体逻辑定价的那块业务，
恰恰是全公司议价能力最弱的。** 更要紧的是，第一大欠款方是**十一科技**（11.63%）、第四是
**世源科技**（4.65%），两家都是总包商——**公司在相当一部分项目上是别人的分包商，价格不是
它定的。** 此外，2025年度股权激励考核未达标，119名激励对象1,815,841股被回购注销
（董监高损失其持有量的35%），**而那份考核的条件是"营业收入**或**净利润"——连"或"都没达到。**

**圣晖：增长引擎在熄火，而且利润质量有折扣。**
在手订单同比仅+4.13%，境内订单13.58亿元、境外15.72亿元——**在大陆晶圆厂投资最热的一年里，
它的订单几乎没有增长。** 上半年收入−16%，靠毛利率修复和坏账转回把利润做正，
**这是"收缩中的改善"，不是增长。** 应收账款计提比例6.08%明显低于同业（柏诚14.11%），
可转债审核问询函也专门问了境外收入与毛利率波动。治理上，**65%股权由台湾上市公司圣晖
（聖暉*SH）经圣晖国际间接持有**，双方以"避免同业竞争承诺"划界——台湾圣晖做台湾市场，
上市公司做大陆与东南亚，**这意味着上市公司的业务边界是被母公司划定的，且其收入已并入
母公司报表，资本配置的第一顺位服务于母公司而非A股小股东。** 最后，**1亿股的总股本**
使它极度波动：一年内20.57元→135.58元→73.82元。

## 5. 什么会改变这个排序——可证伪的检验点

1. **柏诚2026年三季报（10月下旬）的单季毛利率。** 若回到11%以上且收入维持增长，
   **它4倍于圣晖的订单增速就会立刻变得比圣晖的高ROE更值钱，排序反转。** 若仍在10%出头，
   在手订单越大越是负担。
2. **圣晖2026年第三季度经营情况报告（预计10月中旬）的在手订单。** 圣晖按季披露订单，
   这是它优于柏诚的一项披露习惯。**若三季度订单从+4.13%跳升，说明东南亚新一轮资本开支
   启动，圣晖将同时具备增长与盈利质量。**
3. **圣晖半年报中的坏账转回金额与毛利率。** 上半年利润增长有多少来自"转回"？
   若剔除后扣非利润仍增长，质量成立；若不成立，圣晖的6.43%净利率就要打折。
4. **柏诚12亿元定增的状态。** 半年报只字未提。终止是好消息（现金够用），推进也是好消息
   （钱能到位）；**最坏的是悬而未决。**
5. **圣晖5.5亿元可转债的发行与转股价。** 已过会，关注发行时点与初始转股价对1亿股小股本的
   摊薄。
6. **两家的收现比。** 柏诚上半年55.9%（上年63.6%）。**这是本轮景气里最灵敏的单一指标——
   如果整个行业的收现比都在下降，说明业主在用付款条件转移压力，那么两家都要下调估值。**
7. **同业第三方参照：亚翔集成（603929）。** 其2026年上半年归母净利润预告4.56亿—5.25亿元
   （同比+183%—+226%），主要来自新加坡项目"金额较大且利润率较好"——**是柏诚的5—6倍、
   圣晖的6—7倍。** 亚翔证明了这条赛道能赚大钱，也证明了赚到钱的是**在正确地区做正确项目**
   的那一家。三家放在一起看，比任何单家的纵向比较都更有信息量。

## 6. 初步排序

**就"生意"而言：圣晖 > 柏诚。** 两倍的ROE、覆盖净利润93%的经营现金流、52%的分红率、
42%的高毛利境外收入、按季披露在手订单的透明度、以及一笔不摊薄股本上限30%的融资方案。

**就"增长敞口"而言：柏诚 > 圣晖。** 在手订单+222%对+4.13%，且是大陆晶圆厂建设的正面
敞口——这个弹性圣晖给不了。

**就"当前价格"而言：圣晖更合理但都不便宜。** 48倍 vs 63倍市盈率；按每单位ROE付出的
价格，圣晖比柏诚低约四成；反向估值所要求的利润倍数，圣晖2.4倍、柏诚3.2倍。

**综合判断：如果只能深入研究一个，选圣晖——因为它的问题（订单不增长）是可以等待和观察的，
而柏诚的问题（放量即降价）是结构性的，且刚刚被分业务毛利率数据逐条证实。**
但这个排序有一个明确的翻转条件：**柏诚三季度单季毛利率站上11%。** 那意味着它的订单弹性
第一次开始以正常价格转化，届时56亿元在手订单的价值会被重新计算。

**最后一条提醒：两只股票在过去十个月里同涨同跌，相关性极高。** 在"洁净室＋半导体资本开支"
这个主题被重新定价时，选股几乎不起作用——**如果你的判断是主题层面的，那么真正的问题不是
"买哪一个"，而是"这个主题在7月腰斩之后是否已经出清"。** 本备忘录不回答这个问题。
